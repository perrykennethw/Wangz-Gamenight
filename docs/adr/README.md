# Architecture Decision Records

This directory records architectural decisions whose rationale would otherwise be easy to lose.

Add an ADR only when the decision is hard to reverse, surprising without context, and the result of a real trade-off. Routine implementation choices belong in code, tests, or pull-request context instead.

## Adding a decision

1. Copy the template below into `NNNN-short-title.md`.
2. Use the next sequential four-digit number.
3. Explain the context, decision, and reason in one to three sentences.
4. Add optional status, considered options, or consequences only when they provide lasting value.
5. Link superseding decisions instead of rewriting history.

## Template

```markdown
# Short title of the decision

In one to three sentences, state the context, what was decided, and why.
```
